## 一、这是什么项目

一个**本地优先的个人日记 + 笔记应用**：React 单页应用 + 同机零依赖 Node 后端 + 硬盘文件存储。给非技术用户「双击 `start-diary.bat` 就能用」的私人写作工具，数据不联网、不受清缓存影响。

- 代码约 4400 行，54 次提交，单人维护
- **明确不做联网部署**（后端是常驻进程 + 本机文件存储，已删除 vercel/netlify 配置）

## 四、⚠️ 关键约定与易踩的坑（最重要的部分）

1. **改后端必须重启进程**才生效；前端 Vite 会 HMR。用户常忘记重启 → 新 API 404。
2. **`store._enqueue` 是串行写队列**：已入队任务内**不能再调用会入队的公共方法**（会死锁）。需要 `_xxx` 无入队内部版本（现有 `_rmFilesByEntry` / `_clearAllFiles` / `_clearAllImages`）。
3. **写入是原子的**：`_writeJSON` 先写同目录 `.tmp` 再 `rename`。**Windows 坑**：目标文件被并发读句柄占用时 `rename` 抛 `EPERM/EBUSY`，必须走 `_renameOver` 退避重试 —— 别"简化"掉。
4. **`entryId` 一律是日期字符串 `YYYY-MM-DD`** → 同一天的日记和笔记**共用**同一个图片/附件池。
5. **素材"移除即删"**：`Editor.onUpdate` 里用 `lib/asset-sync.ts` 做前后快照 diff，把移出正文的 `fileId`/`imageId` 立即 `DELETE`（覆盖 × 按钮 / 键盘删除 / 剪切 / 整段替换）。
   ⚠️ 切换日期走 `setContent(value, false)` **不触发 onUpdate** —— 这是机制成立的前提，**别改成 `true`**。
6. **后端接口语义（易混）**：
   - `DELETE /api/entries` = **只清日记条目**，不动素材（`clearEntries`）
   - `DELETE /api/data` = **全量重置**（日记+笔记+图片+附件，`clearAllData`），供"还原备份"
   - `GET /api/files`、`/api/images` **不带 `entryId` 时返回全部**（供清理孤儿素材）
7. **后端默认只监听 `127.0.0.1`**（`HOST` 环境变量可放开）。本机 `localhost` **优先解析 `::1`**，所以 Vite 代理与 bat 探活都**写死 `127.0.0.1`**（前端探活除外，因 Vite 绑 `::1`）。
8. **dev server 配置别动**：`Cache-Control: no-store` + `cacheDir: node_modules/.vite-dev`，用于根治浏览器 `ERR_CACHE_READ_FAILURE` 白屏（改回默认会复发）。
9. **用 curl 测本机服务必须加 `--noproxy '*'`**，否则走代理会返回 502，误判成服务挂了。
10. 编辑器内容存 **TipTap JSON**；图片以 `file:<id>` 作 src + `imageId/entryId` 属性；附件是 `fileAttachment` 节点（`fileId/entryId/name/size/mime`）。
11. 提交信息用**中文 conventional commit**（feat/fix/style/refactor/perf/docs）。
12. Node 用托管路径：`C:\Users\quan\.workbuddy\binaries\node\versions\22.22.2-2\node.exe`。

## 六、已实现功能

- **日记**：一天一篇，富文本（加粗/斜体/H2/列表/引用/行内代码）、标题、心情 emoji、标签、600ms 防抖自动保存 + **切日期/卸载时 flush**
- **笔记**：一天多篇，独立存储；卡片式编辑；年历查找模式（12 个月平铺、木板色高亮、点日期跳转）
- **图片与附件**：工具栏上传（图片限 `image/*`，附件任意类型、多选、20MB 上限）；附件渲染为可下载卡片；**移除即删后端文件**
- **森林**：当月日记长成像素树，叶子预览（含前后间隔天数）、搜索高亮
- **日历**：全年 12 月，有日记的日期显示心情
- **搜索**：标题+正文全文检索，覆盖日记与笔记（带来源标签），笔记结果跳 `/notes?date=` 深链
- **设置**：主题切换、导出 JSON/Markdown、导入还原（保留原 id）、旧 IndexedDB 迁移、清空日记/清空笔记（分开）、**维护 → 清理未引用素材**
- 404 兜底路由、浅/深色主题、移动端优先响应式
